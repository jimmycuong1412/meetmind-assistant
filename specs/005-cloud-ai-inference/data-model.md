# Data Model: Cloud AI Inference Mode

**Feature**: 005-cloud-ai-inference
**Date**: 2026-04-14

---

## New Entities

### CloudProviderConfig

The user's cloud AI configuration. Exactly one instance per device; persists across
app restarts. Stored in encrypted DataStore (Tink + Android Keystore).

| Field | Type | Constraints |
|-------|------|-------------|
| `provider` | `CloudProvider` | `GEMINI` or `CLAUDE`; null if unconfigured |
| `encryptedApiKey` | `String` | AES-256-GCM ciphertext (Base64); stored in DataStore; never exposed in logs |
| `isEnabled` | `Boolean` | User toggle; defaults to `false` on fresh install |
| `connectionStatus` | `ConnectionStatus` | `UNCONFIGURED`, `CONNECTED`, `ERROR` |
| `lastValidatedAt` | `Long?` | Unix timestamp (ms) of last successful validation call; null if never validated |

**CloudProvider** (enum):
- `GEMINI` — Google Gemini API via Firebase AI Logic SDK (`gemini-2.5-flash`)
- `CLAUDE` — Anthropic API via official Java SDK (`claude-haiku-4-5-20251001`)

**ConnectionStatus** (enum):
- `UNCONFIGURED` — no key saved
- `CONNECTED` — key saved and last validation succeeded
- `ERROR` — last validation or API call returned an auth error (401/403)

**Validation rules**:
- `isEnabled` can only be `true` when `connectionStatus == CONNECTED`
- Setting `isEnabled = true` when `connectionStatus != CONNECTED` MUST be rejected
  by the Settings UI with a prompt to add/fix the API key

### CloudInferenceRequest

A single cloud API request for one suggestion. In-memory only; not persisted.

| Field | Type | Constraints |
|-------|------|-------------|
| `id` | `UUID` | Generated on creation |
| `questionText` | `String` | ≤150 tokens; the detected question (FR-005) |
| `userRole` | `String` | ≤20 tokens; snapshot of `ContextProfile.role` |
| `sessionMode` | `SessionMode` | `MEETING` or `INTERVIEW` |
| `provider` | `CloudProvider` | Snapshot of `CloudProviderConfig.provider` at request time |
| `dispatchedAt` | `Long` | Unix timestamp (ms) when HTTP request was sent |
| `firstTokenAt` | `Long?` | Unix timestamp (ms) when first response token was received; null until then |
| `completedAt` | `Long?` | Unix timestamp (ms) when streaming completed or was cancelled |
| `status` | `RequestStatus` | `PENDING`, `STREAMING`, `COMPLETED`, `TIMED_OUT`, `FAILED` |

**RequestStatus** (enum):
- `PENDING` — dispatched, no response yet
- `STREAMING` — first token received, tokens arriving
- `COMPLETED` — stream closed normally
- `TIMED_OUT` — no first token within 5 seconds → fallback triggered
- `FAILED` — HTTP error or network failure → fallback triggered

**Timeout rule**: If `(now - dispatchedAt) > 5000ms` and `firstTokenAt == null`,
status transitions to `TIMED_OUT` and the on-device engine is triggered.

### Extended: Suggestion (from specs 001/004)

The existing `Suggestion` entity gains two new fields:

| Field | Type | Change |
|-------|------|--------|
| `inferenceMode` | `InferenceMode` | NEW — `ON_DEVICE` or `CLOUD` |
| `cloudRequestId` | `UUID?` | NEW — FK → `CloudInferenceRequest.id`; null for on-device suggestions |

**InferenceMode** (enum):
- `ON_DEVICE` — generated by llama.cpp (spec 004 engine)
- `CLOUD` — generated by Gemini or Claude via cloud API

The `freshnessState` logic from spec 004 is unchanged and applies to cloud
suggestions identically.

---

### CloudBadgeState

A derived UI state — not a stored entity. Computed each render from
`CloudProviderConfig.isEnabled` and the most recent `Suggestion.inferenceMode`.

| Value | Display | Condition |
|-------|---------|-----------|
| `HIDDEN` | No badge | Cloud mode disabled |
| `CLOUD_ACTIVE` | "☁ Cloud" (primary colour) | Cloud mode enabled, last suggestion was `CLOUD` |
| `FALLBACK` | "⚡ On-device (cloud unavailable)" (muted) | Cloud mode enabled, last suggestion was `ON_DEVICE` due to fallback |

## Entity Relationships (additions to spec 004 model)

```
CloudProviderConfig (singleton)
    │
    │ provider + decryptedKey (runtime only)
    ▼
CloudInferenceRequest ──────────────────────► Suggestion (extended)
        │                                           │
        │ id = cloudRequestId                       │ inferenceMode = CLOUD / ON_DEVICE
        └───────────────────────────────────────────┘
```

The `Session` entity (spec 001/004) gains no new fields — inference mode is
captured per-suggestion, not per-session, because fallbacks mean a single session
can contain both cloud and on-device suggestions.

## LLM Prompt Schema (Cloud Path)

The cloud provider receives a structured prompt. Data minimisation (FR-005) is
enforced here — this is the complete set of data sent per request.

### Gemini prompt (Firebase AI Logic)

```kotlin
generativeModel.generateContentStream(
    content {
        systemInstruction = """
            You are a real-time ${sessionMode.label} assistant.
            User role: ${userRole}
            Mode: ${sessionMode.name}
            In INTERVIEW mode, respond in first person as the user.
            In MEETING mode, respond as a collaborative contribution.
            Be concise: 2–3 sentences, maximum 200 tokens.
        """.trimIndent()
        text("Question: $questionText")
    }
)
```

### Claude prompt (Anthropic SDK)

```kotlin
MessageCreateParams.builder()
    .model(Model.CLAUDE_HAIKU_4_5)
    .maxTokens(200)
    .system("""
        You are a real-time ${sessionMode.label} assistant.
        User role: $userRole
        In INTERVIEW mode, respond in first person. In MEETING mode, respond collaboratively.
        Be concise: 2–3 sentences.
    """.trimIndent())
    .addUserMessage("Question: $questionText")
    .build()
```

**Token budget enforcement**:
- System prompt: ≤80 tokens (role + mode instruction)
- Question: ≤150 tokens (FR-005 hard cap; truncate at word boundary if over)
- `maxTokens` / `thinkingBudget = 0`: 200 tokens output cap (FR-010)
- Total round-trip: ≤430 tokens — well within free-tier limits for both providers

## Storage Summary (additions to spec 001/003/004)

| Entity | Persistence | Store |
|--------|-------------|-------|
| `CloudProviderConfig` | Permanent | DataStore (Tink-encrypted via Android Keystore) |
| `CloudInferenceRequest` | Session lifetime | In-memory only |
| `Suggestion.inferenceMode` | Session lifetime | In-memory only (v1) |
| API key (plaintext) | Never persisted | Runtime memory only (decrypted on demand, not cached) |
