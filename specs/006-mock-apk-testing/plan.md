# Implementation Plan: Mock APK Testing (No Physical Device)

**Branch**: `feature/006-mock-apk-testing` | **Date**: 2026-04-15 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/006-mock-apk-testing/spec.md`

## Summary

This plan establishes a complete JVM-only test suite for the MeetMind Assistant
Android app — runnable via `./gradlew test` with no emulator, no physical device,
and no API credentials. The suite automates 5 of the 7 spec 005 smoke tests using:

- **Robolectric 4.14** for Android framework mocking (Keystore, DataStore, NotificationManager)
- **FakeCloudStreamingProvider** abstraction to isolate Firebase AI Logic SDK and Anthropic SDK
- **FakeClock** injection into `CloudInferenceEngine` for deterministic TTFT tests
- **MockWebServer** for network audit (no audio leaves device verification)

Two spec 005 production-code changes are required: (1) extract `CloudStreamingProvider`
interface, (2) inject `Clock` and `connectivityChecker` into `CloudInferenceEngine`.

## Phase 1: Design

### Interface Extraction (production code change)

`CloudInferenceEngine` currently holds direct references to `GeminiInferenceClient`
and `ClaudeInferenceClient`. To enable injection of fakes, both clients will
implement a new `CloudStreamingProvider` interface:

```kotlin
// inference/CloudStreamingProvider.kt
interface CloudStreamingProvider {
    fun streamSuggestion(request: CloudInferenceRequest): Flow<InferenceEvent>
    suspend fun validate(): ValidationResult
}
```

`CloudInferenceEngine` constructor becomes:

```kotlin
class CloudInferenceEngine(
    private val context: Context,
    private val apiKeyStore: ApiKeyStore,
    private val configRepository: CloudProviderConfigRepository,
    private val geminiProvider: CloudStreamingProvider,
    private val claudeProviderFactory: (apiKey: String) -> CloudStreamingProvider,
    private val onDeviceFallback: OnDeviceFallback,
    private val clock: Clock = SystemClock,
    private val connectivityChecker: () -> Boolean = { isNetworkAvailable() }
)
```

`AppContainer.kt` wires this with the real clients; tests inject fakes.

## Key Implementation Notes for /speckit.tasks

1. **Production code changes come first** — `CloudStreamingProvider` interface
   and `CloudInferenceEngine` constructor refactor must land before any tests
   compile. Tasks should be ordered: interface → engine refactor → AppContainer
   update → test helpers → test classes.

2. **`ClaudeInferenceClient` needs a `baseUrl` override** for `NetworkAuditTest`
   to point at `MockWebServer`. Add an optional `baseUrl: String?` parameter to
   `streamSuggestion()` or expose it via the `AnthropicOkHttpClient.builder()`.

3. **`robolectric.properties` resource file** must be at
   `app/src/test/resources/robolectric.properties` (not `androidTest`).

4. **DataStore in tests**: Use `PreferenceDataStoreFactory.create()` with a
   temporary file in `System.getProperty("java.io.tmpdir")` OR use the
   in-memory `DataStore` stub. Either works under Robolectric.

5. **`FakeClock` + coroutine time**: For the timeout test, use
   `kotlinx.coroutines.test.runTest` with `advanceTimeBy(5001)` to trigger the
   `withTimeout(5000)` cancellation deterministically.
